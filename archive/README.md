# Archived material

This directory contains historical algorithm copies, superseded or failed
experiment outputs, runtime logs, old tests, paper build products, and reference
papers retained for provenance. These files are not part of the default
reproduction workflow and should not be imported by current scripts.

The archive was created during the 2026-09-17 public-release reorganization.
No archived file was deleted solely because its purpose was uncertain.

`simulation-4/` contains the retired Wang/GrFA factor-model experiment,
including its generators, runners, factor-count script, and associated logs.

`manuscript/` contains the superseded manuscript PDF and referee report.
`real-data-reconstruction/` contains generated FEMNIST reconstruction image
exports, including the earlier settings variant; their CSV result records remain
in `results/real_data/`.

`experiment-scans/` contains superseded threshold and parameter scans,
rank-matched comparisons, and alternate housing and Table 4 outputs. The
selected paper results remain in `results/`. `project-notes/` preserves the
working change note that was kept outside the tracked documentation.
