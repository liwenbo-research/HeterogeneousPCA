the exact command manifest `arguments.txt`.

and error outputs, the selected FE threshold scan, and the FE/KT/PerPCA table

recorded method-level CSV outputs. `results/real_data/table4/400x400/`
contains the completed icon-on-texture summary/detail tables and PNG
reconstructions.

`archive/simulation-4/` and are retained only for provenance.

Older scans, failed runs, logs, LaTeX build products, and alternative result
variants remain under `archive/` for provenance and are not recommended as
primary results.
